# 개인사이트 스킨 10종 기획서 — 구현 전 콘셉트 (이슈 #4)

> **기획 전용.** 스킨 HTML·엔진 변경 없음. 3-9 기본 디자인 개편 및 스킨규격 v1.5 확정 후 **스킨 1개 = 이슈 1개**로 제작한다. 

## 공통 디자인·품질 기준

- 10종은 **라이트 5 / 다크 5**. 외부 폰트·이미지·CDN·링크 리소스 없이 **HTML 1개 + `<style>` CSS만**으로 구현 가능하게 기획한다. 아트워크·프로필은 사이트가 제공하는 동적 이미지이며 스킨의 별도 이미지 자산이 아니다.
- 완성 스킨 1개 **30KB 이하 목표**(규격상 업로드 상한 100KB와 별개). CSS 레이아웃은 Grid/Flex·절제된 정지형 그라데이션으로; 동영상·캔버스·스크립트·무거운 블러 애니메이션 없음.
- `{{menu}}`·`{{content}}`·`{{player}}` 필수 슬롯을 유지한다. `{{profile}}`, `{{socials}}`, `{{banner}}`, `{{footer}}`, `{{ad_top}}`, `{{ad_left}}`는 규격에 따라 선택하고, 재생·방명록·가사는 공통 엔진의 동작을 건드리지 않는다. UI 버전·스킨규격 v1.5 변경 시 마크업을 재확인한다.
- 아래 대비는 WCAG 상대휘도 기준 `(L밝음+0.05)/(L어두움+0.05)`로 계산한 **글자색:바탕색** 비율(소수 둘째자리). 모든 본문·보조 글자 및 강조 글자/버튼의 바탕/패널 대비는 **4.5:1 이상**이다. 라이트의 강조 채움 버튼 글자는 흰색, 다크는 짙은 바탕색을 쓰되 제작 시 별도 재검증한다.
- 재생 바는 고정 위치(모바일 safe-area 포함), `prefers-reduced-motion` 준수. PC·모바일에서 곡 재생과 메뉴 접근성이 우선. 실제 서비스의 로고·상표·캐릭터·화면 구조를 복제하지 않는다.
