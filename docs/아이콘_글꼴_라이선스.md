- 쓰는 법(visitor.js): `ic('play')` → `<svg class="aml-ic"><use href="/_app/icons.svg?v=1#play"></use></svg>`. 색은 글자색(currentColor).
- 아이콘 추가: Lucide 에서 SVG 를 받아 `<symbol id="이름" viewBox="0 0 24 24"><g fill="none" stroke="currentColor" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round">…</g></symbol>` 한 줄을 `icons.svg` 에 넣고 `src/ui.js` 의 `ICON_SPRITE` `?v=` 를 올린다. 파일은 8KB 이하로 유지.
- MP3 인코더(3-11): 관리 화면에서 **WAV 를 골랐을 때만** Web Worker(`/_app/wav-mp3.js`)가 받는다. 방문자 화면·관리 화면 첫 로드에는 없다. `mp3.wasm` 은 같은 사이트에서 바이트로 받아 넘긴다(로더 안의 unpkg 주소는 쓰지 않음). 관리 화면 CSP 에 WebAssembly 컴파일만 허용하는 `'wasm-unsafe-eval'` 추가(자바스크립트 eval 은 그대로 금지).
- 글꼴은 스킨 글꼴 목록에 `Pretendard` 가 있고 애플 기기가 아닐 때만 visitor.js 가 `pretendard.css` 를 붙인다. 화면에 나온 글자의 조각만 받는다.
